## Getting the code

You'll need git installed. Run `git --version` to check; if it isn't installed, download it from git-scm.com.

1. Open a terminal and go to the folder where you want the project:
```bash
   cd path/to/your/projects
```
2. Clone the repository:
```bash
   git clone https://github.com/s-aranwrap/calhacks26.git
   cd calhacks26
```

Cloning automatically sets this repository as a remote called `origin`. You can confirm with:
```bash
git remote -v
```

## Staying up to date

To pull the latest changes:
```bash
git pull
```
